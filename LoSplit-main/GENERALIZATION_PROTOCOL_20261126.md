# 泛化研究与参数核查

日期：2026-11-26。工作目录：`work/LoSplit-main`。

## 研究目标与验收

核查现行特征参考版的全部方法选择；用观测数据学习的统计量替代固定词袋表示规则；评估 Cora 上 GTA、UGBA、DPGBA、SPEAR 与 GCN、GAT、GraphSage 的配对表现，并检查 Citeseer 适配。

用户目标：CA 接近匹配无防御基线或更高、ASR < 1%、Precision > 90%、Recall > 90%，方法超参数至多三个。CA 差值逐项报告，保留整数计数和全部登记配置。

## 执行记录

1. 现行方法核查：检测倍数、参考集比例/数量、参考风险、模型成员数、数值容差、修复规则，以及随机种子和组件选择分别登记。
2. 统计量研究：比较公开表示规则与从参考特征学习的距离/尺度分数；每一步写明输入、目的、条件和可证结论。
3. 实现与实验：新文件实现独立研究分支；复用固定快照与已有评分定义；三种骨干共享检测规则。旧报告中的种子作为开发资料，另登记确认资料。
4. 核验：模型重载预测一致、训练与评分输入分离、保存源码和数据摘要、同图正常节点 CA、检出节点的真实类别正确率。

## 理论与统计口径

定理明确列出假设。排序校准讨论交换性条件；分离与恢复命题给出可测量的充分条件。性能目标通过实测计数判定。0/n 的 ASR 同时提供单侧置信上界；同一固定划分的重复种子分别报告。

基线保持相同骨干、宽度、训练轮数与初始化种子。新增统计量的候选配置全部保留，测试指标用于报告。方法选择的开发用途单独标注。

## 开发结果与确认配置

20 组开发拟合保留于 `runs/generalization_20261126/development_grid/study.json`。四种设置的中位数填补版本均达到训练 Precision>97%、Recall=100%、ASR=0；SPEAR 同图 CA 优于盒投影对照。默认确认配置据此登记为 γ=1、ρ=0.2、α=0.005、单成员普通/参考模型、中位数填补、联合幅值/有效维数分数。γ=1.5、2 的开发检测检查显示 UGBA 召回下降，保留其结果。

确认样本重新使用种子 41、42、43 生成 Cora 四种设置；Citeseer 另生成种子 41。原始数据划分由项目 `utils.get_split` 固定为种子 10，生成与分类器种子另行改变。跨骨干使用同一已生成快照，以对齐输入。新样本生成在参数选择期间进行；新样本的评价输出在上述配置登记之后读取。

Citeseer 原始缓存有 15 个精确零行。泛化分支将零行作为独立点质量，正幅值分布由非零参考行拟合。该规则在跨数据集拟合前加入。原特征版新增运行时表示检查，并支持 Citeseer、GAT、GraphSage，参数及旧默认研究设置保留。

## 第二个候选：逐统计量范围包络

种子 31 的既有 UGBA 快照中，第一候选的 Precision 降至 70.18%，对应 17 个正常训练节点误报。该次结果完整保留。进一步使用每个统计量自己的经验范围，消除单个合成分数阈值对验证划分的敏感性。新分数为 max(a/a_max,a_min/a,r/r_max,r_min/r)，范围由全部可用验证特征确定，精确零行单列。默认 γ=2、ρ=0.2、α=0.005，修复采用经验中位数。种子 31 的检测开发对照中，γ=2、3 均得到四种设置 Precision=Recall=100%。

第二候选的独立评价先使用新生成的 Cora 种子 41，后扩展 42、43；Citeseer 种子 41 在生成后评价。GAT 使用 CPU 严格复现设置，当前 PyTorch 版本的 GPU 注意力聚合算子缺少相应实现；此前两次 GPU 检查的错误单列记录。
