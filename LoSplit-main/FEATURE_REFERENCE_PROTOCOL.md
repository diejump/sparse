# 原节点特征一致性扩展：实验登记

日期：2026-11-26。

研究问题：将原节点特征的一致性检查及修复加入现有结构与参考判别流程，能否在同一组参数下覆盖 Cora 的 GTA、UGBA、DPGBA、SPEAR？

主指标固定为 CA、ASR、Precision、Recall、FPR。目标为 Precision、Recall 高于 90%，ASR 尽可能低，同时报告与匹配成员数基线的 CA 差异。

特征模型采用本地 Cora 公开预处理规则：归一化二值词袋行，允许全零行。候选修复规则根据观测行的最常见正值识别保留的特征位置，再恢复等值归一化表示。数值容差初始固定为 1e-6。

开发使用已分析的 SPEAR 两份快照和其他三种方式的 seed16 快照。开发阶段保留全部结果。参数与实现冻结后，再生成新种子的四种快照进行确认。

初始方法参数沿用检测倍数 2、参考比例 0.2、排序参数 0.005。先以单成员完成方法检查，再比较既有三成员设置。隐藏维数和学习率与配对基线一致，训练均为 200 轮。

必要对照：原参考版、仅新增自身特征检测、特征检测加修复、去掉结构检测、去掉参考判别、截断负值并归一化的简单预处理。

检测和修复只读取当前观测特征、图、训练和验证身份及允许的记录标签。原始特征、真实目标名单、测试标签、生成器内部选定的特征列只在实验评分及条件核对中使用。

理论拟证明：正常表示的精确保留；共同特征值可识别条件；恢复后的支持集合与精确误差公式；结构和自身检测并集的精确率、召回率关系；固定模型输出的误差传播界；参考判别的条件排序界。

所有性能数值由实验产生，数学结论逐条给出假设和证明。研究贡献的表述依据实际对照结果与文献比较形成。

## 执行记录与推荐配置

确认阶段使用配置冻结后新生成的种子 31、32、33，四种方式各生成三份快照；原图与原数据划分沿用项目设置。分类器种子与该次生成种子相同，其他防御参数一致。确认阶段预先列出检测扩展、检测与修复、原参考版、匹配无防御四种设置，全部结果保留。

确认结果中，两种扩展的检测与 ASR 指标一致，保留原特征的检测扩展在标准干净图上具有更高 CA。后续按同一批未修改节点核对触发图中的 CA，发现 SPEAR 下保留原特征版本的平均 CA 为 73.09%，修复版本为 82.59%。最终运行入口保留冻结方案的 feature_repair=unique_mode、feature_members=1。feature_repair=none 继续作为对照，两种图输入对应的 CA 分别保存。
